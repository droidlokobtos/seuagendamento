# Recursos do aplicativo

`icon.svg` e `splash.svg` são modelos provisórios da identidade visual. Antes de publicar nas
lojas, exporte a versão final como `icon-only.png` (1024 × 1024 px) e `splash.png`
(2732 × 2732 px), mantendo-os nesta pasta. Depois execute `npm run mobile:assets` para gerar
os tamanhos nativos de Android e iOS.
